# Changelog

## 1.0.0 - 2026-09-22

- Initial public release.
- Added NOAA CO-OPS observations, current harmonic prediction and high/low forecast support.
- Added configurable datums, units, polling, forecast window, stale interval and retained history.
- Added observed-level, predicted-high, residual, stale and recovery automation events.
- Added first-run baselining, request invalidation, partial-data handling and test commands.
